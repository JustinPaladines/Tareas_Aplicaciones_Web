<h2> Explicar diferencia entre global y privado.</h2>
-
En mensajería, un chat global es un espacio donde todos los usuarios de la plataforma pueden participar, se comparten mensajes que cualquiera puede leer y responder, lo que lo convierte en un lugar para anuncios generales o conversaciones públicas. 
Un chat privado, en cambio, está limitado a un grupo pequeño o a una conversación entre dos personas. Solo quienes han sido invitados pueden ver y escribir mensajes, lo que lo hace más adecuado para temas personales o información que no se quiere compartir con todos.

<h2> ¿Es mejor enviar privado por IP o Socket ID? </h2>
Es mucho mejor usar el Socket ID. La IP no es segura porque varias personas conectadas al mismo Wi-Fi comparten la misma IP y si se manda un mensaje por ahí, lo podrían leer todos en la misma casa u oficina. 
El Socket ID, en cambio, es como un número único para cada pestaña, y se asegura que el mensaje le llegue únicamente a la persona correcta.
